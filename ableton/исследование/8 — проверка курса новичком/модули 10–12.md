# Обратная связь: модули 10–12 глазами новичка

Хорошо: у модулей ясная линия (луп → форма → переходы → живой проход → баланс → EQ → компрессия → проверка → мастер → привычки), почти у каждого шага есть понятное «зачем», числа конкретные, а «Трек №1» и черновики 5–6 честно доводят трек до публикации.
Мешает сильнее всего: (1) команда **Save a Copy** в четырёх уроках оставляет ученицу работать в старом файле, и цепочка файлов «аранжировка → микс → мастер» ломается; (2) базовые слова сведения (dB, Hz, полоса EQ, Makeup, LUFS-числа, true peak) так и не объяснены с нуля, хотя курс пользуется ими с модуля 3; (3) несколько шагов спорят с прошлыми модулями: rumble, сайдчейны и EQ на возвратах уже стоят, запись 64 тактов из 9-3 лежит в Arrangement, группы ни разу не собирали.
Ещё мелочи: «пад» вместо «пэд» (в курсе «пад» уже значит ячейку Drum Rack), «рамбл» вместо rumble, два вопроса теста проверяли меню, а не понимание. В модулях почти не было «Попробуй»: добавлено пять, со ссылками на атлас ритмов.

Всего находок: 46.

## m10-1 Ловушка вечного лупа
- m10-1 · шаг 1 · File → Save a Copy сохраняет копию, а работа продолжается в исходном «Трек №1». Вычитание испортит исходный луп, хотя «зачем» обещает обратное · заменено на Save Live Set As (урок 1-4) и фразу «Дальше работаешь в этом файле».
- m10-1 · шаги 2–4 · В уроке 9-3 ученица уже записала 64 такта в Arrangement, и там обещано, что из них «вырастет полная аранжировка». Здесь же снова пишется сцена с 1-го такта поверх этой записи · добавлен шаг: «есть запись 9-3? Это и есть полный луп, пропусти запись». Запись сцены осталась запасным вариантом.
- m10-1 · шаг 5 · Выделение «от 1-го до 9-го такта» подходит только для 8 тактов. Сколько раз жать ⌘ D, непонятно · выделяется вся запись, добавлено: для 8 тактов около 23 нажатий, для 64 тактов два.
- m10-1 · шаг 6 · Выделить такты сразу на четырёх треках, которые стоят не рядом, нельзя. «Тональные звуки» не объяснены · шаг разбит: трек за треком; «тональные» = звуки с высотой нот.
- m10-1 · текст «Начинай, пока луп не идеален» · Слово «дроп» без объяснения · добавлено одно предложение: что такое дроп.
- m10-1 · нет «Попробуй» · Якорь объяснён только абстрактно · добавлен tip «Попробуй»: даб-техно и ритуальная перкуссия в атласе (бочка-якорь и ручные барабаны), потом тест на выключение слоёв в «Треке №1».
